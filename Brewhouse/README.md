# BrewHouse ☕

A responsive specialty coffee shop landing page built with **HTML5 and CSS3**. BrewHouse features a warm, modern design that highlights handcrafted coffee, the café's story, and visitor information.

## ✨ Features

- **Hero Section** — Welcoming introduction with call-to-action buttons.
- **Coffee Menu** — Displays featured drinks with images and descriptions.
- **Our Story** — Introduces the café's values and atmosphere.
- **Visit Us** — Shows location details, opening hours, and contact information.
- **Responsive Design** — Adapts to desktop, tablet, and mobile screens.
- **Interactive Styling** — Includes hover effects, smooth scrolling, and button transitions.
- **Accessibility** — Uses semantic HTML, descriptive image alt text, and visible keyboard-focus indicators.
- **Performance Considerations** — Uses lazy loading for below-the-fold images and prioritizes the hero image.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Queries
- CSS Custom Properties

## 🚀 Getting Started

No installation or build tools are required.

1. Clone the repository:

   ```bash
   git clone https://github.com/KarriEmmanuelWatson/TheOdinProject.git
   ```

2. Open the project folder:

   ```bash
   cd TheOdinProject/Brewhouse
   ```

3. Open `index.html` in your browser.

   Alternatively, use the **Live Server** extension in Visual Studio Code for a convenient local development experience.
